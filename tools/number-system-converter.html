चारों नंबर सिस्टम क्या हैं?

हाथ से बदलने का तरीका

Decimal → Binary: 2 से लगातार भाग दो, शेषफल उल्टे पढ़ो। जैसे 13: 13÷2=शेष 1 → 6÷2=शेष 0 → 3÷2=शेष 1 → 1÷2=शेष 1 → उल्टा पढ़ो = 1101

Binary → Decimal: हर अंक को उसकी जगह की घात (2 की) से गुणा करके जोड़ो। 1101 = 8+4+0+1 = 13

Decimal → Hex: 16 से भाग दो। 255 = 15×16 + 15 = FF (10=A, 11=B … 15=F)
