हाथ से बदलने का तरीका

Decimal → Binary: 2 से लगातार भाग दो, शेषफल उल्टे पढ़ो। जैसे 13: 13÷2=शेष 1 → 6÷2=शेष 0 → 3÷2=शेष 1 → 1÷2=शेष 1 → उल्टा पढ़ो = 1101

Binary → Decimal: हर अंक को उसकी जगह की घात (2 की) से गुणा करके जोड़ो। 1101 = 8+4+0+1 = 13

Decimal → Hex: 16 से भाग दो। 255 = 15×16 + 15 = FF (10=A, 11=B … 15=F)

Decimal, Binary, Octal, Hex – क्या हैं?

कंप्यूटर की दुनिया में संख्याएं अलग-अलग आधारों में लिखी जाती हैं:

  • Decimal (आधार 10): हमारी रोज की गिनती – 0 से 9 तक अंक
  • Binary (आधार 2): सिर्फ 0 और 1 – कंप्यूटर की असली भाषा; जैसे 10 = 1010
  • Octal (आधार 8): 0-7 तक अंक – पुराने कंप्यूटर/परमिशन सेटिंग्स में
  • Hexadecimal (आधार 16): 0-9 और A-F – कलर कोड (#FF0000), मेमोरी एड्रेस में

उदाहरण: decimal 255 = binary 11111111 = hex FF। कंप्यूटर साइंस के छात्रों के लिए यह कन्वर्टर एग्जाम और प्रैक्टिस दोनों में काम आता है – नंबर डालते ही चारों रूप तुरंत।

CS Students के 5 fundas

  • Powers of 2 रटें – 1,2,4,8,16,32,64,128,256,512,1024।
  • Hex = 4 bits – binary को 4-4 में बांटकर hex पढ़ें।
  • KB/MB: 1024-based (1KB=1024B) vs 1000-based (disk companies!)।
  • ASCII: A=65, a=97, 0=48 – programming में काम का।
  • Subnet: /24 = 255.255.255.0 = आखिरी 8 bits hosts।

अक्सर पूछे जाने वाले सवाल (FAQ)

Binary क्या है?

0-1 का system (base 2) – computer की भाषा। 1010₂ = 10। हर digit = bit (8 bits = 1 byte)।

Hexadecimal क्यों इस्तेमाल होता है?

Binary का short form – 4 bits = 1 hex digit। Colors (#FF5733), memory addresses, MAC सब hex में। A=10...F=15।

Decimal → Binary कैसे?

2 से भाग देते जाओ, remainders उल्टे लिखो: 13 → 1101₂। Calculator steps दिखाता है।

1s और 2s complement क्या?

Negative numbers का binary रूप: 1s = bits उल्टो, 2s = 1s + 1। Computer घटाव 2s complement से करता है।

Octal कहां लगता है?

Unix file permissions! (chmod 755 = rwxr-xr-x)। हर octal digit = 3 bits।
