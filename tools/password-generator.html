🔐 मज़बूत पासवर्ड जनरेटर

सेटिंग चुनें और बटन दबाएं – पासवर्ड आपके ब्राउज़र में ही बनेगा, कहीं नहीं भेजा जाता।

यहाँ आपका पासवर्ड आएगा…

मज़बूत पासवर्ड की पहचान

  • लंबाई सबसे ज़रूरी है – 12–16 अक्षर से छोटा पासवर्ड आसानी से टूट सकता है
  • मिला-जुला हो – बड़े-छोटे अक्षर, अंक और चिन्ह सब
  • अनुमान लगाने वाली बातें न हों – नाम, जन्मतिथि, 123456, password, mobile number कभी नहीं
  • हर website का अलग पासवर्ड – एक लीक होने पर सब खतरे में न आएं

यह tool कैसे काम करता है?

यह आपके browser के cryptographic random generator से पूरी तरह यादृच्छिक (random) अक्षर चुनता है। पासवर्ड बनता आपके device पर है – किसी server पर नहीं भेजा जाता, सेव भी नहीं होता। पेज बंद करने पर गायब।

पासवर्ड सुरक्षित रखने के 5 नियम

  1. पासवर्ड किसी से साझा न करें – न दोस्तों से, न "technical support" के बहाने फोन करने वालों से
  2. हर जगह अलग पासवर्ड याद रखना मुश्किल है – इसलिए password manager (जैसे ब्राउज़र का अपना) इस्तेमाल करें
  3. दो-चरणीय सत्यापन (2FA) जहाँ मिले ज़रूर चालू करें – SMS/OTP या authenticator app
  4. एक ही साइट का पासवर्ड कई साल न चलाएं – समय-समय पर बदलें, खासकर email और banking का
  5. सार्वजनिक कंप्यूटर पर login करने से बचें; करना पड़े तो बाद में पासवर्ड बदल दें
💡 पैसे वाली साइट्स के लिए: बैंक/UPI वाले पासवर्ड ज़्यादा लंबे (20+) रखें और सिर्फ अपनी निजी device से login करें।
🔒 प्राइवेसी की गारंटी: यह tool offline तक चलता है – कोई network कॉल नहीं, कोई डेटा सेव नहीं।

मज़बूत Password कैसे बनाएं?

  1. लंबाई चुनें – 12–16 characters (bank/email के लिए 16)।
  2. Aa/0-9/@#$ सब ON रखें – 4-type mix सबसे मज़बूत।
  3. Generate दबाएं – password आपके browser में ही बनता है, server पर नहीं जाता।
  4. Copy + save – password manager (Bitwarden free) या diary में।
  5. हर site का अलग password – 1 leak से सब hack नहीं!

Password Security के 5 नियम

  • 2-Step ON – Gmail/bank/WhatsApp सब पर (password leak भी हो तो safe)।
  • Same password NEVER – 1 site hack = सब hack।
  • OTP किसी को नहीं – bank भी नहीं मांगता, मांगने वाला ठग!।
  • haveibeenpwned.com पर email check करें – leak में हो तो तुरंत बदलें।
  • Bitwarden (free) – सारे passwords 1 master password में safe।

अक्सर पूछे जाने वाले सवाल (FAQ)

मज़बूत password क्या होता है?

12+ characters + UPPERCASE + lowercase + digits + symbols का random mix। Generator से बनाकर manager में save करें।

Password याद कैसे रखें?

Password manager (Bitwarden free) इस्तेमाल करें – सिर्फ 1 master password याद रखना होता है।

2-Step Verification क्या है?

Password + OTP/app-code की double lock। Password चोरी भी हो जाए तो account safe – Gmail/bank सब पर ON करें।

क्या ये generator safe है?

100% – password आपके browser में बनता है, किसी server पर नहीं जाता। Page refresh = password गायब, इसलिए copy करके save करें।

OTP fraud से कैसे बचें?

OTP = आपकी digital चाबी। Bank/police/दोस्त बनकर मांगे तो 100% fraud – तुरंत 1930 (cyber helpline) पर report करें।
